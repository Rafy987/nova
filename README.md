# NOVA — Live Voice AI Assistant

A voice-first AI assistant in the browser: speak, NOVA listens, thinks and answers out loud.

> Work in progress. Phase 1: HUD layout, design tokens, static orb.

## Run locally

```bash
npm install
cp .env.example .env.local   # add your own keys (never commit .env.local)
npm run dev
```

Open http://localhost:3000.

## Stack

Next.js 16 (App Router) · TypeScript · Tailwind CSS v4
